# RecallRadar

**Product Recall Impact and Supply-Chain Traceability Platform**

## About

RecallRadar is a database-driven platform designed to trace the impact of recalled components and product batches across a supply chain.

It helps identify affected products, inventory and downstream distributors when a component or batch is recalled.

## Technology Stack

- **Frontend:** Next.js, TypeScript
- **Relational Database:** MySQL
- **NoSQL Database:** Neo4j
- **Version Control:** Git and GitHub

## Key Features

- Product, component and batch management
- Supplier and distributor information management
- Inventory tracking
- Product recall management
- Graph-based supply-chain traceability
- Identification of affected products and distributors
